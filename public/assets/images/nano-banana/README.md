# Nano Banana Pro Imagery Directory

This directory is designated for photorealistic, human-centered legal imagery generated via Nano Banana Pro in Antigravity.

## Quality Standards:
- Photorealistic raster images only (no SVG cartoons, dolls, puppets, or mannequins).
- Realistic lawyer attire, natural lighting, genuine courtroom/chambers setting.
- Inspect faces, fingers, and postures prior to deployment.
- Never present AI-generated portraits as actual named firm advocates.
